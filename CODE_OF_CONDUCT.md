# Code of Conduct

## The short version

Be straightforward and civil. Critique code, not people.

## What is expected

- Assume good faith. Most disagreements are misunderstandings about context.
- Be specific. "This breaks on Windows because paths are separated by `\`" is useful;
  "this is wrong" is not.
- Accept that maintainers may decline a change. OmniKey has deliberate constraints — most
  notably that it never phones home — and a well-built contribution can still be out of
  scope.
- Respect people's time. Search existing issues before filing, and include enough detail to
  reproduce a problem.

## What is not acceptable

- Personal attacks, insults, or demeaning comments
- Harassment of any kind, public or private
- Discriminatory language or imagery
- Publishing someone's private information without permission
- Sustained disruption of discussions

## Scope

This applies in issues, pull requests, discussions, commit messages, and any other project
space, including when representing the project publicly.

## Enforcement

Report problems privately to the maintainer via
[GitHub](https://github.com/GurinderRawala). Reports are handled confidentially.

Maintainers may edit or remove comments, commits, issues, and pull requests that violate
this code, and may block repeat offenders from the repository. Enforcement is proportionate:
a first lapse usually gets a warning, not a ban.
